# Gregory Archive

Browse, search and visualize the Timothy E. Gregory slide archive: 31,000+ photographs of Greece, Byzantium and the Mediterranean.

**Site:** <https://tregodan-msu.github.io/gregoryarchive/>

31,289 images.

## Using the site

- **Browse and search:** https://tregodan-msu.github.io/gregoryarchive/browse/ (gallery, table, map, charts and a full-screen viewer).
- **About:** [About the archive](https://tregodan-msu.github.io/gregoryarchive/), [Methodology](https://tregodan-msu.github.io/gregoryarchive/methodology/), [Takedown policy](https://tregodan-msu.github.io/gregoryarchive/takedown-policy/).
- **Permanent links:** every record has one, of the form `https://tregodan-msu.github.io/gregoryarchive/#slide/<ID>`.
- **Download the data:** the Export menu on the site gives what is shown, or all records, as CSV or JSON. The complete catalogue is also in this repository as [`data/archive.json`](https://tregodan-msu.github.io/gregoryarchive/data/archive.json).

## The Isthmia archives

One of a family of connected archives for the excavations at Isthmia:

- [Clement Coin Catalog](https://tregodan-msu.github.io/clementcoins/): Browse and search the coins from the UCLA/OSU/MSU excavations at Isthmia catalogued by Paul A. Clement: obverse and reverse photographs, mints, dates, weights and find contexts.
- [Isthmia Archives](https://tregodan-msu.github.io/isthmia-site/): searches all the archives together

## About this repository

This repository holds the **published website only**. It is written by an automated build and replaced in full each time the site is published, so changes made here are lost: please do not edit it or open pull requests against it. The catalogue is maintained by the archive team in a separate editor. To report a problem with a record, use the contact above.
